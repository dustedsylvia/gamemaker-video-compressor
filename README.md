# gamemaker-video-compressor
A simple Python script to compress a video for GameMaker Studio 2 (in a 480p game).  

Have you ever noticed that GameMaker is absolutely sh-t at playing videos? ...No? Well here you go anyway.  
This tiny script compresses a video into a format that GameMaker can play without lagging too badly. It currently only runs on Windows, but (if you know what you're doing) it should be trivial to port it to Linux or MacOS.  

This script was originally made for [SP!Dusttale - Desperation](https://gamejolt.com/games/spdusttaledesperation/1018009). go check it out haha
